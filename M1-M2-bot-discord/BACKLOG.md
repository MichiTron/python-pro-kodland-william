# Backlog (tarea 115552)

## 3 ideas de mejora para el bot de mi compañero

1. Agregar un comando de ayuda (`$help`) que liste todos los comandos con una breve descripción.
2. Validar las entradas de los comandos (por ejemplo, números negativos o texto en lugar de número) y responder con un mensaje claro en vez de fallar.
3. Mover el token a una variable de entorno o a un archivo `.env` fuera del repositorio, para no subirlo a GitHub.

## 3 sugerencias recibidas para mi bot

1. Agregar un comando para tirar dados con formato NdN, como `$roll 2d6`.
2. Mostrar un mensaje de error amigable cuando una API de imágenes no responde.
3. Añadir más comandos de imágenes de animales (por ejemplo gatos) y un comando que elija una al azar.
