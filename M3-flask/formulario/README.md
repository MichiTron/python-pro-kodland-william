# Formulario con Flask (M3L3)

- 115545 El backend del formulario: `submit_form` lee todos los campos con `request.form` y los pasa a `form_result.html`. Código a pegar: `submit_form_solucion.py`.
- 115547 Mejorando el formulario: `submit_form` además escribe cada dato en `form.txt`; `form_result.html` tiene estilos en `static/css/style.css`. `form.txt` es un ejemplo tras rellenar el formulario.

Ejecutar:

    pip install flask
    python main.py
