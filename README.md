# Python Pro - Kodland - William Rueda

Soluciones de las tareas de clase y de casa del curso Python Pro de Kodland, módulos 1 a 8.

| Carpeta | Módulo | Contenido |
|---|---|---|
| `M1-ejercicios/` | M1 | Generador de contraseñas, adivina el número, acortador de cadenas |
| `M1-M2-bot-discord/` | M1-M2 | Bot de Discord con funciones propias, comandos con APIs y backlog |
| `M2-web/` | M2 | Página web con estilo Kodland y widget del tiempo |
| `M3-flask/` | M3 | Rutas Flask, calculadora ecológica, formulario con backend, generador de memes |
| `M4-diario/` | M4 | Diario del programador con base de datos y autorización |
| `M4-portafolio/` | M4 | Sitio web de portafolio |
| `M5-ia/` | M5 | Pie de foto con OpenCV, resúmenes con NLTK, dataset de aves |
| `M6-vision/` | M6 | Detección de aves, verificador real vs IA, SafetyAI con ImageAI |
| `M7-bot-clasificador/` | M7 | Bot de Discord que clasifica imágenes con un modelo de Teachable Machine |
| `M7-traductor-voz/` | M7 | Traductor de voz con selección de idioma |
| `M7-juego-pronunciacion/` | M7 | Juego "Habla Correcto" de pronunciación |
| `M8-agile/` | M8 | Roles de Scrum, retrospectiva y misión secreta |

Cada carpeta tiene su propio README con instrucciones de ejecución.
