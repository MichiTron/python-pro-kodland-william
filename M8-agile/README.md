# M8L1 - Agile y Scrum

## Roles de un equipo Scrum (131388)

Ejemplo: app para alquilar paraguas en una ciudad lluviosa.

- **Product Owner**: representa al cliente y a los usuarios. Define la visión, crea y prioriza el Product Backlog
  (mapa de puntos con paraguas, alquiler y devolución, pagos, avisos de lluvia) y acepta el trabajo terminado.
- **Scrum Master**: facilita daily, planning, review y retrospectiva, y quita bloqueos al equipo
  (por ejemplo, conseguir acceso a la API de pagos).
- **Equipo de desarrollo**: diseña, programa y prueba la app y las estaciones, estima las tareas y entrega
  un incremento funcional al final de cada sprint.

## Retrospectiva (131391)

- Resultados: bot de Discord con comandos propios, calculadora ecológica y diario con Flask y base de datos,
  bot clasificador de imágenes.
- Qué salió bien: dividir el código en funciones y archivos, usar Git y GitHub, leer documentación.
- Qué mejorar: organizar el tiempo y no acumular entregas; escribir pruebas pequeñas antes de terminar.
- Retos: entornos virtuales y dependencias, variables en plantillas de Flask, conectar la base de datos con formularios.
- Planes: sprints semanales con tareas pequeñas, terminar el portafolio y empezar un proyecto con reconocimiento de voz.

## Misión secreta (131392)

"EstudiaConmigo": app que convierte apuntes (fotos o audio) en resúmenes, tarjetas de repaso y cuestionarios,
y organiza un plan de estudio según las fechas de exámenes.

- Equipo: Product Owner, Scrum Master, dos desarrolladores backend en Python, frontend/móvil,
  especialista en visión por ordenador y diseñador UX.
- Primer sprint (2 semanas): subir una foto de apuntes, extraer el texto y generar un resumen y 5 preguntas.
